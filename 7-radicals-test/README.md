# Тест «7 радикалов»

Опросник для самопроверки по методике Виктора Пономаренко из книги «Практическая характерология. Методика 7 радикалов».

- 42 утверждения, по 6 на каждый радикал: истероидный, эпилептоидный, паранойяльный, эмотивный, шизоидный, гипертимный, тревожный.
- Результат — психологический профиль: все радикалы по силе, цифровой код и разбор трёх ведущих (сильные стороны, подходящие задачи, зона внимания, как с вами общаться).
- Один файл `index.html`, без зависимостей: открывается в любом браузере, работает и без интернета (шрифты тогда стандартные).

Автор методики подчёркивает, что она «нетестовая» и строится на наблюдении за поведением, поэтому результат — гипотеза, которую стоит проверить реальными поступками.
